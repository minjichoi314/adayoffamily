# 다른 하루, 같은 마음 — 가족 공감 탐험 보드게임

React나 별도 빌드 도구 없이 HTML, CSS, 순수 JavaScript로 실행하는 수업용 웹앱입니다.

## 실행
`index.html`을 브라우저에서 열면 됩니다. GitHub Pages에 올리면 온라인으로 사용할 수 있습니다.

## 파일 구성
- `index.html`: 웹앱 화면 골격
- `css/style.css`: 화면 디자인과 반응형 규칙
- `css/print.css`: 결과물 및 수료증 인쇄 설정
- `js/data.js`: STEP, 미션, 가족 카드, 힌트 자료
- `js/app.js`: 진행, 저장, 입력, 잠금 해제, 인쇄 기능

메인 제목은 한 줄로 표시하며, 첫 화면 탐험 지도에는 길을 걷는 청소년 탐험가 삽화를 배치했습니다. STEP 표지는 그림 없이 진행 글자만 담은 네모 이정표로 표시합니다.

## GitHub Pages 배포
1. GitHub에서 `family-empathy-game` 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `css`, `js`를 저장소 최상위에 업로드합니다. 폴더를 압축해 올리는 대신 압축을 풀고 파일 경로를 그대로 유지합니다. GitHub Desktop에서 저장소 폴더를 열어 커밋하고 Push하면 폴더 구조가 유지됩니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. Build and deployment에서 **Deploy from a branch**를 선택하고 `main` 및 `/(root)`를 지정한 뒤 저장합니다.
5. 잠시 후 `https://계정명.github.io/family-empathy-game/`에서 확인합니다.

저장소의 최상위 경로를 사용하며 CSS와 JavaScript는 상대 경로로 연결되어 하위 경로 배포에서도 작동합니다.

## 저장과 개인정보
작성 내용은 현재 사용하는 브라우저의 localStorage에 저장됩니다. 다른 기기와 공유되지 않고 교사가 중앙에서 열람할 수 없습니다. 학교 공용 기기에서는 활동 후 `진행 초기화`를 이용하세요. 기본 활동은 실제 가족 이야기가 아닌 가상의 페르소나를 대상으로 합니다.

## 그림 스타일
가족 유형, 가족별 일상, 학교·방과 후 활동, 가족 구성원, 감정, 힌트 카드에 참고 그림과 같은 2D 파스텔 동화 삽화를 사용합니다. 그림 파일은 `assets` 폴더에 있으며 선택 카드 영역과 글자 영역을 분리해 표시합니다. 가족 카드에는 한부모·조손·다문화·재혼·입양·대가족 그림과 설명이 들어 있습니다. STEP 2의 아침·학교·방과 후·저녁 장면에는 조손·한부모·다문화·입양가족과 다양한 또래 구성을 담았습니다. STEP 3의 감정, 가족 구성원, 대화 상황도 그림 선택형으로 제시합니다. 나 전달법은 상황·감정·이유·바람을 채우는 문장 완성형입니다. 수료증에는 별도의 책과 월계수 메달 그림을 제목 위에 배치하고 발급번호·수료자·날짜를 담았습니다. 담당 교사 서명 및 마지막 축하 문구는 제외했습니다. 감정 카드는 남자 아기와 여자 아기 얼굴로 감정을 표현합니다. 가족 유형, 학교·방과 후·가족 활동, 감정, 힌트 카드 등 모든 그림 자산은 최신 참고 이미지의 깨끗한 2D 파스텔 동화 삽화풍으로 통일했습니다. 힌트 삽화는 가족 이해, 페르소나 이해, 가족 관계, 일상 관찰, 감정 이해, 소통, 공감, 대화, 새로운 하루의 키워드에 맞춰 각각 다르게 구성했습니다. 삽화 매핑과 대체 텍스트는 `js/app.js`의 `art()` 함수에서 관리합니다.

## 수정 방법
가족 카드, 미션 제목, 힌트 문구와 선택지는 `js/data.js`에서 수정할 수 있습니다. 색상과 화면 배치는 `css/style.css`에서 조정합니다.

### 최신 탐험 지도 (v12)

메인 탐험 지도는 노란 유채꽃 들판과 산책길 삽화를 배경으로 사용합니다. 청소년 탐험가 삽화는 왼쪽에 배치했고, 지도 위 나무 푯말은 STEP 1–3 번호만 표시합니다. 지도 내부의 장소 설명과 진행 범례는 제거했습니다. 앱은 React 없이 HTML, CSS, 바닐라 JavaScript로 구성되어 있습니다.

### 지도 푯말 문구 업데이트

세 푯말에 다음 문구를 표시합니다: STEP 1 ‘다양한 가족을 만나다’, STEP 2 ‘오늘 너의 하루를 만나다’, STEP 3 ‘함께 행복한 내일을 그리다’.

푯말은 배경 삽화와 어울리도록 나뭇결, 둥근 모서리, 나무 기둥과 풀 장식을 적용하고 STEP 상태별로 따뜻한 색을 유지합니다.

푯말 마감은 수채화 꽃밭과 어울리도록 나뭇결 줄무늬와 강한 테두리, 그림자 대비를 줄였으며 기둥 아래 풀 장식을 제거했습니다.

탐험 지도 푯말은 CSS 카드 모양 대신 수채화풍 투명 PNG 삽화를 사용합니다. 푯말 일러스트에는 초록 풀 장식이 없으며 STEP 문구는 삽화 위에 겹쳐 표시됩니다.

푯말 이미지는 버튼 안에 별도 이미지 요소로 배치해 크기와 표시를 안정화했습니다. 큰 화면에서는 폭 300px, 작은 화면에서도 폭 195px로 표시되며, 이미지가 늦게 로드되더라도 판이 보이도록 배경색을 추가했습니다.

푯말 최종 표시에서는 겹쳐 보이던 CSS 보조 판을 제거하고, 수채화 PNG 푯말만 사용합니다. STEP 문구는 삽화 위에 표시하고 세 번째 푯말을 위쪽 가장자리에서 조금 내렸습니다.
